# Three_phase_PMSM_Drive_system
MATLAB/Simulink implementation of a Permanent Magnet Synchronous Motor (PMSM) drive system, featuring motor modeling, inverter integration, and control system design. Includes subsystem-based architecture, simulation models, and performance analysis of speed, torque, and three-phase current responses.

## Overview

This project presents the design and simulation of a Permanent Magnet Synchronous Motor (PMSM) Drive System using MATLAB/Simulink. The model demonstrates the complete drive architecture, including the PMSM, three-phase inverter, control subsystem, and performance analysis.

The objective of this project is to understand the operation of modern electric drives and gain hands-on experience in subsystem design, simulation modeling, and control system implementation using Simulink.

## Features

* PMSM mathematical and simulation model
* Three-phase inverter-based motor drive
* Modular subsystem design in Simulink
* Speed and torque control implementation

* Dynamic and steady-state performance evaluation
* MATLAB/Simulink based simulation environment

## Project Architecture

The PMSM drive system consists of the following major subsystems:

1. **DC Supply**

   * Provides input power to the inverter.

2. **Three-Phase Inverter**

   * Converts DC power into three-phase AC power required by the PMSM.

3. **Control Subsystem**

   * Generates control signals for motor operation.
   * Regulates motor speed and overall system performance.

4. **PMSM Model**

   * Simulates the electrical and mechanical behavior of the motor.

5. **Monitoring and Analysis**

   * Observes speed, torque, currents, and other performance parameters.
